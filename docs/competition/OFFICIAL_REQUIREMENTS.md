## 本作品必须坚持的表述

2026-10-26 按现状更新（10-14 原版写于 Agent、MCP Server 实现之前）。完整的“不要说 / 应该说”对照见 [答辩准备手册](DEFENSE_BRIEFING.md) 第 10 节。

- MCP Server 已实现：官方 SDK、本机 stdio、两个只读工具；没有远程 HTTP 部署和鉴权。Function Calling 是我们调用模型的方式，和 MCP 是两回事。
- “AI 继续查”是受约束的检索 Agent：模型规划检索、调用工具，但只能找证据，不能判定真伪或宣布文献不存在；不宣称完整自主 Agent。
- RAG 以实际召回片段为证据；摘要核查只能得出摘要范围内的结论；没有用向量检索。
- PDF/DOCX/TXT 的文字提取属于多格式文本输入，不算多模态；多模态指截图 / 拍照识别参考文献。
- 自建 29 条文献回归集与受控论断样本不能推出真实世界总体准确率；盲测数字要带口径和样本量；场景测试修复后的数字是同一批复测，不是盲测。
- 技术/演示材料完备不等于已满足报名、团队、仓库访问或正式提交条件。
