## 讲稿事实与使用边界

- 英文 Agent 历史 7 条是“当时被规则确认”，不是 7 条全部正确：4 条已核实中 1 条配到同名新文章；3 条信息有误中 1 条配到旧版报告、1 条无法确认。随后规则修复未经过新的独立复测。
- 中文检索的 33/75 是找到三站论文页的条数；仅 1 条自动确认。多数缺作者，另有译名和相近文章；不能称为“33 条已核实”或真实场景准确率。
- 历次新样本按旧口径的复核误报为 10.1%、9.1%、11.7%、18.0%、5.6%；其中相近候选也计为误报。第五批新口径 4.6% 不能与旧口径混比，更不能推广成“总体误报只有 5%”。
- 图片 16/16 来自合成印刷体；检索 24/24 只检测出处进入前六段，样本全是原文支持的论断，不是判断准确率。
- 隐藏文字检测有未覆盖情况，正常深色底白字也可能被列出。提示可能需要检查，不判断作者意图。
- 589 项为当前 README 记载的测试数；当天检查若有变化，先同步数字再合成最终音频。
- 所有证据都需要人工复核。模型结构校验、引句定位与逐字段规则可以约束流程，但不等于正确性保证。

- Europe PMC 不可用时，可能只取到摘要；保留实际范围和结论，不把人工粘贴全文称为自动取得。没有引句时，不制作虚假定位画面。
- AI 继续查未找到、余额不足、限流或失败时，保留真实步骤和结果。确需重录时记录原因，最终音画对应。
- 中文论文页若要求登录，只展示实际可见状态；不显示个人账户，也不把未读取的作者说成已核对。
- MCP 客户端连接或调用失败时，保存实际错误并修复后重录，不以静态结果卡充当真实调用。
- 每章保留原始 WebM、动作时间戳、等待区间和实际结果摘要；最终 MP4 与原始素材分开保存。
- 使用 ffprobe 核对时长、分辨率、编码及音轨；按章节抽帧，检查字幕、隐私、结果与讲稿、合成标识和剪短等待标识。
