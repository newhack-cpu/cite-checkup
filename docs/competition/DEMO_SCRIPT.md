# 引用体检：演示操作与普通话讲解稿

状态：录制操作稿；成片规格与验收由实际视频单独证明。新功能段落应在最终验收通过后录制，不在失败界面上配“成功”的旁白。

## 正式参赛版：目标 6 分钟

官方要求 5-8 分钟、MP4、1080p 或以上、普通话讲解。建议录制 1920×1080；控制台、编辑器和环境配置均不进入录制。镜头以真实应用窗口和真实操作为主，等待模型时解释边界，长等待可剪切但需标记“等待已缩短”。

| 时间 | 真实操作 | 普通话讲解要点 |
|---|---|---|
| 00:00-00:35 | 首页及两个工作区 | “引用体检解决两个不同的问题：参考文献能否核实，以及文献提供的证据是否支持正文的一条论断。我们把数据库事实核验和语言模型的证据阅读分开，让每个结论都能回到来源。” |
| 00:35-01:20 | 导入一份已检查的 PDF 或 DOCX，展示提取预览、切换参考文献片段，确认应用 | “导入后先显示提取文字，由用户确认范围再放入核查框。PDF 目前只读取文字层；图片扫描件不会伪装成识别成功。导入本身没有请求模型。” |
| 01:20-02:10 | AI 辅助解析 2-3 条公开文献，等待实际数据库结果 | “这里选择 DeepSeek 辅助解析。模型通过受约束的工具调用提供字段，服务端核对原文依据，再进入 Crossref、DOI.org 和 OpenAlex。模型不能自行宣布文献存在，也不能替换错误作者来美化结果。” |
| 02:10-02:50 | 展开字段问题及来源；下载 Markdown 报告 | “同一篇文献中年份、作者或期刊不符，会逐字段解释。查不到不等于编造；数据库故障也不会当成查无此文。未确认同篇的候选保留原文，必须人工确认。” |
| 02:50-03:45 | 切换论断核查；输入实际验收的公开 DOI 与一条论断，提交并展开证据 | “第二条链路先取得可用摘要或用户提供的文本，分块检索，只把召回片段送给模型。结果分为支持、部分支持、矛盾和证据不足，每条引句都要在对应原文片段中找到。这里的标签明确写着摘要，所以不把它当成全文审阅。” |
| 03:45-04:35 | 切换已验收的受控证据样例；展示支持与矛盾，明确标签 | “这段是标明为合成的测试材料，用来验证系统行为，不是真实研究结果。改换论断后，系统会依据同一段材料给出相反判断；没有相关证据时应承认证据不足，而不是补写一条看似合理的出处。” |
| 04:35-05:10 | 展示取消按钮、来源/引句定位、手机布局截图或真实窄屏 | “用户可以停止等待。缺密钥、连接失败或结果不能通过校验时会清楚提示。纸张与印章视觉对应核查报告，但颜色和分数都不能替代判断理由与来源。” |
| 05:10-05:45 | 展示技术 PDF 的架构与验证页，停留在实际数字 | “我们分别验证固定输入回归、真实数据库、真实模型以及浏览器交互。29 条文献回归样本全部符合预期，只能说明这组样本；新增论断与导入测试的结果请看本页记录，不能推成总体准确率。” |
| 05:45-06:05 | 回到应用，总结适用范围 | “引用体检面向论文写作自查。它帮助找到应复核的位置，不能替代阅读全文和学术判断。当前没有 OCR、自主规划 Agent 或付费系统。下一步优先扩大独立测试集和真实用户验证。” |

各段时间含合理操作与阅读停顿；按实际模型响应调整，成片总时长必须经媒体工具核对。不得用拉长空白或机械循环凑到 5 分钟。没有普通话音轨的静默录屏不是正式参赛视频。

## 快速演示版：目标 4 分钟

适合现场预览或向同学介绍，不满足官方正式视频的 5 分钟下限。

1. 00:00-00:25：问题与两条核查链路。
2. 00:25-01:05：导入预览、确认片段、选择 AI 辅助解析。
3. 01:05-01:45：真实文献结果、错误字段、来源和报告。
4. 01:45-02:45：公开 DOI 摘要核查与可定位引句，强调摘要范围。
5. 02:45-03:25：一条已验收的受控矛盾/不足案例，明确是测试材料。
6. 03:25-04:00：验证数字、隐私边界、已知限制。

## 录制前检查与异常分支

- 使用最终生产构建；确保模型可用状态，避免把固定响应模拟当成真实联网演示。
- 只使用公开引文和无隐私的演示文本；不展示密钥、终端环境变量或浏览器密码界面。
- 对照最终验收证据选取已运行成功的输入；精确保留输入、模型、来源、输出和录制日期。
- 若公开 DOI 没有可用摘要，保留“没有摘要”的真实结果，切换到明确标为用户提供的合成演示证据。不能把人工粘贴的全文说成系统自动取得。
- 若网络失败，展示失败状态后重试或改录；不在后期把失败字幕替换成成功结论。
- 原始屏幕录制、最终 MP4、字幕/旁白源和时长分辨率检查单分别保留。剪辑只压缩等待，不伪造查询过程。
