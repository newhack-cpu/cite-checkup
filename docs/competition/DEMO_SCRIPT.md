# 引用体检：演示操作与普通话讲解稿

状态：2026-10-16 按当前功能重写，讲解由本人录制；逐字讲稿见 [`narration.json`](narration.json)。10-14 的成片（6 分 39 秒）是旧版本，里面没有拍照识别、AI 检索 Agent、隐藏提示词检测、开放全文论断核查和 MCP，需要重录。新功能段落必须在当天实际跑通后录制，不在失败界面上配“成功”的旁白。

## 正式参赛版：目标 7 分 15 秒

官方要求 5–8 分钟、MP4、1080p 或以上、普通话讲解。建议录制 1920×1080；控制台、编辑器和环境配置不进入录制（MCP 一段除外，见下）。镜头以真实应用窗口和真实操作为主，等待模型时讲解边界，长等待可剪掉，但要标“等待已缩短”。

| 时间 | 真实操作 | 讲解要点 |
|---|---|---|
| 00:00–00:35 | 首页、两个工作区、隐私提示 | 两个问题分开查；每个判断都能回到数据库记录或原文片段 |
| 00:35–01:20 | 参考文献框上方点“拍照 / 截图识别”，上传照片或粘贴截图；对照原图后确认填入 | 浏览器先缩小图片、去掉位置信息；视觉模型只转写不判断，看不清写 [?]；16/16 逐字一致，但只是印刷体样本 |
| 01:20–02:15 | 开始体检；展开“信息有误”的字段差异和规范写法；展示“查无此文”和“无法核验”；下载报告 | 逐字段比对；查不到 ≠ 编造；真实论文盲测误报 16.0% → 10.1%，之后又修了 9 类规则，新盲测集待运行 |
| 02:15–03:05 | 在一条“无法核验”的结果上点“AI 继续查”，等每一步出现 | 模型规划检索、每步写理由；候选仍由规则逐字段确认；不能把文献判成编造；盲测确认 7 条，复核后补了 2 条保守规则 |
| 03:05–03:50 | 导入测试 PDF，展示红色隐藏文字提示框 | 日经亚洲报道 17 篇 arXiv 预印本藏了写给 AI 审稿的指令；列出页码、方式和原文，并从导入文字中去掉 |
| 03:50–04:50 | 论断核查：输入中文论断和 DOI，展示“证据支持”、开放全文范围、混合检索、扩展检索词，定位原句 | 读到 Europe PMC 全文，这句话不在摘要里；词面检索 → 扩展 → 重排；24 条论断命中率 75% → 100% |
| 04:50–05:30 | “试用矛盾演示材料”；再换一条材料没涉及的论断；展示停止按钮 | 合成材料只检查行为；矛盾和证据不足要分开；失败不包装成结论 |
| 05:30–06:05 | MCP 客户端里让 AI 调用 `verify_references` | 同一套核验开放给其他 AI；结论与网页端相同 |
| 06:05–06:45 | 技术说明 PDF 第 11 页（验证方法与实测结果） | 459 项自动测试；所有评测都写明样本和局限，不是总体准确率 |
| 06:45–07:15 | 回到首页 | 中文覆盖、开放全文范围、没有用户研究；下一步先跑新盲测集、找真实写作者试用 |

各段时间含操作和阅读停顿，按实际模型响应调整；成片总时长必须用媒体工具核对。不要用拉长空白或循环画面凑时长；没有普通话音轨的静默录屏不是正式参赛视频。

## 快速演示版：目标 4 分钟

适合现场预览或答辩开场，不满足官方正式视频的 5 分钟下限。

1. 00:00–00:25：两个问题、一个原则。
2. 00:25–01:10：截图识别 → 体检 → 一条信息有误的字段差异。
3. 01:10–01:50：AI 继续查一条无法核验的条目。
4. 01:50–02:30：导入测试 PDF，展示隐藏提示词提示框。
5. 02:30–03:30：DOI 开放全文论断核查，定位到 Results 原句。
6. 03:30–04:00：验证记录与局限。

## 异常分支

- Europe PMC 暂时不可用时，论断核查会退回摘要，那句话不在摘要里，结果会变成“证据不足”。这时保留真实结果并解释原因，或者稍后重录；不能把人工粘贴的全文说成系统自动取得。
- AI 继续查没找到时，如实展示“结论不变”和每一步记录，说明它只找证据、不下结论。
- 网络或模型失败时，展示失败状态后重试或改录；不在后期把失败字幕替换成成功结论。
- 原始录屏、最终 MP4、讲解音轨和时长 / 分辨率检查单分别保留。剪辑只压缩等待，不伪造查询过程。
