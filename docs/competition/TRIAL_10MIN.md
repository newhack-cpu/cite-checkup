# 10 分钟试用包（找同学、老师试用用这一页）

目的：拿到真实用户的数据，补上材料里“实用性”“社会价值”最缺的证据。每人 10 分钟，5–10 人就够。**只记真实结果，不编、不美化**；有人觉得不好用，原样记下来同样有用。

完整版（老师 20–30 分钟、带 SUS 问卷）见 [TRIAL_GUIDE.md](TRIAL_GUIDE.md)。

## 发给试用者的话（可直接复制到微信）

> 你好！我们做了一个查论文参考文献真假的小工具，想请你用自己论文（或作业）的参考文献试 10 分钟，帮我们记几个数。网址：https://www.modelscope.cn/studios/kgkvybu111111/cite-checkup?mode=full ，不用注册，第一次打开要等半分钟左右。只粘贴参考文献列表，不要贴论文正文。谢谢！

## 试用步骤

1. 从自己的论文里复制 **整份参考文献列表**（10 条以上最好）。
2. **先手工核对其中 5 条**：去知网、百度学术或 Google Scholar 逐条查题名、作者、年份、期刊对不对，**记下用了几分钟**。
3. 打开网址，把整份列表粘进去，点“开始体检”，**记下工具查完整份用了多少秒**（结果卡上方有用时）。
4. 看工具标出的“需要处理”“相近候选”的条目，点“详情”对一下，**判断其中有几条真的有问题**（写错、查不到、撤稿）。
5. 打个分：愿不愿意以后写论文时再用（1–5 分），再写一句意见。

## 记录表（每人一行）

用 [trial-10min.csv](trial-10min.csv)（Excel 能直接打开），或者照下面的格式发文字给我们：

| 列 | 怎么填 |
|---|---|
| 编号 | T01、T02……，不写真名 |
| 身份 | 本科生 / 研究生 / 老师 |
| 参考文献条数 | 粘贴进工具的总条数 |
| 手工核对 5 条用时（分钟） | 第 2 步 |
| 工具整份用时（秒） | 第 3 步 |
| 工具标出的条数 | “需要处理”加“相近候选”一共几条 |
| 其中确实有问题的条数 | 第 4 步自己确认的 |
| 再用意愿（1–5） | 第 5 步 |
| 一句话意见 | 好的不好的都写 |

## 收回来之后

把表发给我（Claude），我会：

- 算人数、条数，手工 5 条和工具整份的用时（**不换算成“节省了多少时间”**，两者范围不同），标出条目里真有问题的比例，再用意愿的分布；
- 原样摘录意见，不挑好听的；
- 写进作品介绍、技术说明 8.2 节“尚缺的证据”和 README，注明是小样本、开发方组织的试用。

## 注意

- 试用者只粘贴参考文献，不上传未发表的论文正文。
- 记录表只写编号，不写姓名、学号、手机号。
- 工具标“相近候选”“待人工”不等于写错，请试用者点详情自己判断。
