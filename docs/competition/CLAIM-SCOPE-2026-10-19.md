# 论断核查：范围错配评测（2026-10-19）

**结论**：只拿到摘要时，判定模型常拿“总体”结果去否定限定了子类的论断，比如用“GPT-4 引文总体 18% 是编造的”否定“GPT-4 引用的书籍章节七成是编造的”。在 47 条论断上各判 3 次、跑两轮：不该判矛盾的 178 次判定里，只判定时错判成“与证据矛盾”38 次（21.3%）；加上范围复核后是 0 次。代价是该判矛盾的 102 次里有 1 次被改成了“证据不足”（只判定时判出 96 次，加复核后 95 次）。复核只在初判为矛盾时进行，每次多一次模型调用，中位约 1.1–1.4 秒。

- 数据集：[`eval/claims-scope/cases.json`](../../eval/claims-scope/cases.json)
- 脚本：[`scripts/eval-claim-scope.mts`](../../scripts/eval-claim-scope.mts)
- 结果：[`eval/results/claim-scope-2026-10-19/`](../../eval/results/claim-scope-2026-10-19/)（最终版是 `v2-context.json`、`v2-context-r2.json`，其余是改进过程）
- 模型：deepseek-flash，判定和复核都不开思考模式、温度为 0

## 起因

10-19 可用性复测时，Europe PMC 全文请求超时，系统退回摘要。摘要只给了 GPT-4 引文总体 18% 是编造的，没有按文献类型细分，“GPT-4 引用的书籍章节七成是编造的”就被判成了“与证据矛盾”。正确结论应是“证据不足”；能读到全文时，这句话由原文 Results 一节直接支持。

## 现在的做法

1. 判定（`judge_claim`）不变。
2. 初判为“与证据矛盾”时，再调用一次模型（`check_scope`）：逐个列出论断里限定范围的词（模型、文献类型、人群、地区、时间、条件），对每个词判断引句里有没有专门针对它的结果。由代码汇总，只要有一个词没被覆盖，就改判“证据不足”。解释里写明缺的是哪个范围，“注”里保留初判和理由。
3. 复核时同时提供引句所在的原文片段，只用来弄清引句里的“这些文献”“阅读成绩”指的是什么；只出现在片段里、没被引用的结果不算数。
4. 复核没完成（网络、格式、超时）就保留初判，并提示人工确认。
5. 不复核“支持”：评测里判定从没把“套用总体数字到子类”的论断判成支持（两轮 42 次里 0 次）；对“支持”也复核，最终版两轮反而会把 0 次和 3 次真支持改掉。

## 评测集

47 条论断，期望结论由评测者标注。“套用总体数字到子类”的论断，“证据不足”和“部分支持”都算对。

- **真实部分 20 条**：三篇 CC BY 4.0 论文的摘要（Walters & Wilder 2023，Kung 等 2023，Bhattacharyya 等 2023），评测时按 DOI 从 Crossref / OpenAlex 实时获取，模拟全文取不到的情况。
- **合成部分 27 条**：评测者编写的 6 段英文结果段落（医学、教育、经济、计算机、公共卫生、护理），开头注明是软件测试用的合成材料、不描述真实研究；论断以中文为主，护理一组用英文。

## 改进过程

同一套 47 条，每版各判 3 次：

| 版本 | 有效判定 | 只判定：错判矛盾 | 复核后：错判矛盾 | 复核错改的真矛盾 |
|---|---:|---:|---:|---:|
| v1 只看引句 | 137 | 14 | 0 | 6 |
| **v2 加引句所在片段 + 集合规则**（两轮） | 139 + 141 | 18 + 20 | 0 + 0 | 0 + 1 |
| v3 限定词标类型，跳过“研究本身”“测量指标”（两轮，已撤回） | 140 + 139 | 15 + 20 | 1 + 0 | 3 + 4 |
| v4 把“研究本身”举例写细（两轮，已撤回） | 139 + 141 | 23 + 23 | 0 + 0 | 5 + 4 |

- 最早试过直接改判定提示词（两版），4 条论断各判 3 次，子类论断仍然全部判成矛盾，已撤回；直接问模型“是不是同一范围”，结果来回摇摆。最后改成列限定词、由代码汇总。
- v1 的 6 次错改有两种情况：引句“Reading scores did not change”没写是谁的成绩，指的是参与项目的学生，这一点只在前文出现；“all three exams”包含 Step 1，模型没看出来。v2 给复核同时提供引句所在片段，并写明“对集合里每一项都成立的结果，覆盖其中任意一项”，这两类错误都消失了。
- v3、v4 都比 v2 差：v3 里模型没有把“参与学生”归为“研究本身”，还把原文片段里的 adults 当成了论断的限定词；v4 写细“研究本身”的例子之后，又认不出“三门考试”包含 Step 1。这段提示词对措辞很敏感，以后再改要先跑两轮评测。

## 局限

- 47 条由评测者编写：真实部分只用了三篇论文的摘要，合成段落句式规整，比真实论文简单。结果只说明“范围错配”这一类错判和复核的副作用，不代表论断核查的总体准确率。
- 判定本身的错复核管不了：“A 国最高 78%，所以 B 国不可能 90%”这类需要推理的矛盾，判定 6 次都给了“证据不足”。
- 复核仍有小概率把真矛盾改成“证据不足”（280 次里 1 次）。这时“注”里保留了初判和理由，用户能看到。
- 复核和判定用的是同一个模型。换模型或改提示词后要重跑：

```bash
NODE_USE_ENV_PROXY=1 pnpm exec tsx scripts/eval-claim-scope.mts --runs=3 --tag=<名字>
```
