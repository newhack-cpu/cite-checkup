# 老师试用指南

目的：请几位老师用真实的参考文献列表试用，记下“人工核对要多久、用工具要多久、工具标出的问题对不对”。这是比赛材料里“实用性”和“社会价值”最缺的证据。每位老师约 20–30 分钟。

## 一、试用前准备（我自己做）

1. 在 `.env.local` 填好 `CROSSREF_MAILTO`（自己的联系邮箱）和 `OPENALEX_API_KEY`（openalex.org 免费申请）。没有 OpenAlex key 时，每天只有约 100 次题名检索，几位老师连着用可能会用完，之后“查无此文”会变成“检索不完整”。
2. 启动生产版（在项目目录的 Git Bash 里依次运行，代理端口按自己的实际情况改）：

   ```bash
   pnpm build
   ```

   ```bash
   NODE_USE_ENV_PROXY=1 HTTPS_PROXY=http://127.0.0.1:7890 HTTP_PROXY=http://127.0.0.1:7890 NO_PROXY=localhost,127.0.0.1,::1 pnpm exec next start -p 3210 -H 0.0.0.0
   ```

3. 打开方式二选一：
   - 在我的电脑上用：浏览器打开 `http://localhost:3210`。
   - 老师用自己的电脑：两台电脑连同一个 Wi-Fi；我在命令行运行 `ipconfig` 查到本机 IPv4 地址，老师打开 `http://<这个地址>:3210`。第一次启动时，Windows 防火墙若询问是否允许 Node.js 访问网络，选“专用网络”允许。
4. 先自己跑一遍“载入示例”，确认 11 条都能出结论，再请老师试用。
5. 准备一张打印的记录表（见第四节），或者让老师直接填电子版。

## 二、怎么用（讲给老师听，3 分钟）

**参考文献体检（左边的工作区）**

1. 把参考文献列表粘进“送检单”：一条一行，或者带 [1]、1. 这样的序号。也可以点“导入 PDF / Word / TXT”从论文里提取，或点“拍照 / 截图识别”上传参考文献页的照片。
2. 点“开始体检”，每条会陆续盖上一个章：
   - **已核实**：在数据库里找到同一篇，信息一致；
   - **有误**（信息有误）：找到同一篇，但作者、年份、期刊或 DOI 有写错的地方；
   - **相近候选**：只找到相似的文献，不能确定是不是同一篇，需要人工看；
   - **查无此文**（疑似不存在）：DOI 不存在或指向别的文献，或者英文期刊论文在两个数据库里都查不到，疑似编造；
   - **已撤稿 / 关注声明**：文献存在，但已撤稿或期刊发了关注声明；
   - **待人工**（无法核验）：图书、学位论文、网页、没有 DOI 的中文期刊等，开放数据库覆盖不到，查不到不代表有问题；
   - **未完成**：数据源暂时出错，可以稍后重试。
3. 点“展开详情”：能看到逐字段比对、按数据库记录生成的规范写法（可复制）和“核查过程”的每一步。
4. 对“待人工”或“相近候选”的条目，可以点“AI 继续查”：DeepSeek 会换着方式再查几个数据库，每一步都显示出来，找到的候选仍由规则确认。
5. 看完后可以“复制修正版清单”或“下载核查报告”。

**正文论断核查（右边的工作区）**

1. 输入论文正文里的一句话，例如“GPT-3.5 生成的参考文献有一半以上是编造的”。
2. 证据来源填这句话引用的文献的 DOI（开放获取论文效果最好），或者直接粘贴原文段落。
3. 结论分四类：证据支持、部分支持、矛盾、证据不足。下面列出判断所依据的原文句子，可以点开看在原文里的位置。

**要提前告诉老师的三点**

- “查不到”不等于编造，所有结论都要人工复核，工具只是帮忙把可疑的条目挑出来。
- 标准核验只把参考文献条目发给 Crossref、OpenAlex、doi.org 这类公开数据库。“AI 继续查”、截图识别、AI 辅助解析和论断核查会把相应文字发给 DeepSeek：未公开的学生论文先征得同意，敏感内容不要用这几项。
- 中文文献目前多数显示“待人工”，这是已知短板。

## 三、试用流程（每位老师）

1. 请老师带一份真实的参考文献列表（15–30 条，中英文都可以），最好是学生论文里还没人仔细核对过的。
2. **人工基线**：老师先用平时的方法核对其中 5 条，计时，记下发现的问题。
3. **用工具**：把整份列表粘进去体检，从粘贴到看完结果计时。
4. **逐条判断**：工具标出的“有误 / 相近候选 / 查无此文 / 已撤稿”，请老师逐条判断是“确实有问题 / 误报 / 拿不准”；再看人工发现、但工具没标出来的问题。
5. 任选一条“待人工”点“AI 继续查”，再试一次论断核查。
6. 填记录表；问一句：“如果指导学生写论文，你会不会让学生先用这个自查？为什么？”

## 五、记录怎么用

- 记录表只写编号和学科，不写老师姓名；要在比赛材料里写“某某老师认为……”，先征得本人同意。
- 汇总后写进 README 和技术说明 PDF 的“试用反馈”：试用人数、平均用时对比、问题标注的准确情况、主要意见，以及据此做了哪些修改。只写实际发生的，样本少就如实写样本少。
